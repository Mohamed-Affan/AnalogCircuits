## 📁 Folder layout

Each available experiment has a numbered folder named `Experiment NN`. Image files inside are named `Objective 1`, `Objective 2`, and so on. Experiment 07 keeps its UJT relaxation oscillator materials in a clearly labeled subfolder.

Only experiments with files currently in this repository are listed above.

## 🔬 Working with the materials

Open an experiment folder to view its objective images and recorded results. The objective numbering follows the files available for that experiment.
